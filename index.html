Release notice

Android evaluation files use debug signing. Windows evaluation files are not publisher-signed. The macOS evaluation build is internally ad-hoc signed and is not Apple-notarized. Replace these signatures with owner-controlled production certificates and complete clean-device acceptance before public store distribution. iPhone/iPad was intentionally excluded.
