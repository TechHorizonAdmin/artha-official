Release notice

Android 1.0.7 is signed with Artha’s owner-controlled release certificate and its package signature has been verified. Windows packages are architecture-verified but still require a recognized publisher certificate to avoid SmartScreen warnings. The macOS package passes strict code-integrity verification but is ad-hoc signed and not Apple-notarized; a paid Apple Developer identity is required for warning-free public distribution. iPhone/iPad is intentionally excluded.
