v1.0.9 · package revision r2 · 10 October 2026

Corrected, audited cross-platform packages

Revision r2 repairs the missing production client configuration discovered in the earlier macOS, Windows, Linux and web artifacts. The corrected export now fails the build if its public Supabase configuration is missing, and the release audit opens each supported package payload to verify the expected backend host before publication.

What changed in r2

  • Added mandatory pre-build validation for the public backend URL and anonymous client key, including protection against placeholders and privileged keys.
  • Added post-export and post-package audits for the web export, macOS ZIP, Windows ZIP and Linux deb; the Android APK retains its dedicated embedded-host audit.
  • Rebuilt macOS, Windows, Linux AppImage, Linux deb and web packages from one corrected production export.
  • Launched the repaired macOS package and verified authenticated live, read-only flows across dashboard, POS, inventory, customers, purchases, returns, GST, accounting, reports, storefront and the Business Type Engine.
  • Kept the earlier v1.0.9 package set preserved as a superseded historical record instead of silently overwriting it.

Release focus

  • Preserves the multi-business, branch, role, inventory, accounting, GST-preparation, CRM, staff, reporting, automation, merchant-commerce and customer-storefront foundations.
  • Completes restaurant modifiers and kitchen flow, provider/resource appointment availability, gym memberships and attendance, pharmacy prescription/batch dispensing, electronics serial/warranty operations, and production recipe/batch/output-lot workflows.
  • Adds protected vertical return lifecycles: medicine quarantine, electronics inspection and non-saleable production waste, with refund and accounting evidence.
  • Retains exact serial, medicine batch and production lot evidence through the relevant POS and receipt surfaces.
  • Improves the approved quality baseline to 328 explicit-any warnings from the earlier ceiling of 336.
  • Builds the merchant and customer storefront web export locally at 3,694 modules.

Verification posture

The release passes TypeScript, quality, migration-safety and vertical contract checks plus database, tenant, commerce, B2B, payment, GST, automation, reporting/export, printing and desktop-security regressions. The dedicated staging database replays all 109 migrations, keeps every public table under RLS, has no missing policy-backed grants and passes rollback-safe tenant, retail and engine-smoke journeys.

Package status

The published download set contains an ad-hoc-signed macOS ZIP, unsigned Windows portable ZIP, Linux AppImage and deb, internal/debug-signed Android arm64 APK, and static web export. Commercial publisher signing, Apple notarization, Windows installer signing, Android production signing/AAB, physical printer/scanner testing, provider credentials and statutory authorization remain external gates.

Version and checksums

The application version remains 1.0.9; r2 is the corrected package revision. Every current file is listed in the SHA-256 manifest and the official r2 GitHub Release. The original v1.0.9 package line and v1.0.8 baseline remain historical records.
