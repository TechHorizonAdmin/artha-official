# Artha public website

Static company and product website for Artha Business Suite v1.0.9.

- The website presents the Artha product scope and release posture without publishing private company records.
- `platform.html` is the public overview of the Artha platform and its connected business capabilities.
- Product recordings and screenshots use synthetic demonstration data.
- The v1.0.9 release hub links to controlled evaluation packages only. Its `downloads/` folder is staged in the canonical company website workspace, not committed to source control.
- Keep each package's signing, runtime and acceptance status beside its download link; do not represent an evaluation package as a public-store release.
- Android evaluation packages must use the `internal` build variant so the current JavaScript bundle is embedded; do not publish a debug developer shell as a standalone app package.
- Do not add customer figures, revenue, legal ownership, provider activation or certification claims without independent evidence.
