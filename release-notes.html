ARTHAPlatform overview

Current release

Artha v1.0.9

Version 1.0.9 strengthens the Artha product foundation while preserving the historical v1.0.8 baseline. It documents what was built and verified without representing every external service as active.

Release focus

  • Aligned application, desktop and Expo metadata to v1.0.9.
  • Improved POS barcode/SKU behaviour so an exact scan adds the matching product directly to the active sale.
  • Applied and verified linked production migrations for business context, branch inventory and local accounting-date foundations.
  • Added a protected branch lifecycle: an active main branch is required, non-main branches may be safely retired only after stock is cleared, and direct deletion is blocked to preserve history.
  • Clarified that a business-type change configures the current business; a separate business uses its own tenant context and isolated operating records.
  • Added a customer-facing, static-host-compatible storefront at /store?slug=merchant-store plus a merchant no-code builder for published copy, section visibility and shareable HTTPS store addresses.
  • Refreshed the public Artha website with product recordings, workflow evidence and current verified source inventory.

Verification posture

The release process includes type and formatting checks, tenant/RPC and database-contract checks, commerce, payment, GST-provider, AI, export, printing and desktop-security contract checks, plus export/package workflows where the build host supports them. The static consumer route was opened from a plain local server; the live database audit confirms the main-branch invariant and reports no cross-business branch-stock records.

Current package delivery

The current macOS, Windows, Android and web packages are retained in Artha’s controlled release library with checksums and platform-gate records. Public GitHub release assets must be uploaded before a public download is offered. An HTTPS host and public store base address must be configured before sharing a merchant link. Provider credentials and callbacks, GST-provider authorization, hardware scan-back, platform signing/notarization, clean-device/platform runtime acceptance, Android/iOS signing and any required hosting/privacy/legal review are controlled release activities. No live payment or official GST filing claim is made by this page.

Historical baseline

Artha v1.0.8 remains a preserved historical certified baseline. v1.0.9 is a separate release branch with its own product, release and company documentation.
