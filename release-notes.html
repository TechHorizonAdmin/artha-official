Verified release

Artha 1.0.7

Release date: 28 July 2026. Supported packages: Android APK and AAB, Windows x64, Windows ARM64, macOS Apple silicon and web. iPhone/iPad is intentionally excluded.

Highlights

  • Owner-signed Android production packages with verified v2 APK signature.
  • System receipt printing with thermal, A4 and compact formats.
  • Inventory barcode-label printing across nine standard label sizes, with Code 39, copy quantities and pricing fields.
  • Responsive interface certification across phone, tablet and desktop viewports.
  • Cross-platform suite spanning commerce, inventory, finance, CRM, people, operations and intelligence.
  • Security, backend configuration and release integrity validation.

Signing status

Android packages use Artha’s owner-controlled release identity. Windows packages still require a recognized publisher certificate for SmartScreen reputation. The macOS package is ad-hoc signed and passes strict integrity verification, but Apple Developer ID signing and notarization are still required for warning-free public installation.

Integrity

SHA-256 checksums are published with the release assets and retained in the corporate release-evidence folder.
